# Hex Battle glossary

- **Dockerfile:** The recipe for building the container that runs Hex Battle's online game service. The companion Compose configuration mounts persistent match storage.

- **Active character:** A living character on the board owned by the current player. It still counts if it already moved this turn. A battering ram resting after a charge does not count until its rest turn ends.
- **Deployment edge:** The leftmost hex of each row for Azure or the rightmost hex for Ember. Characters deploy on their own edge; items cannot be placed on either edge. The wider staggered rows have an extra hex but still have one outermost hex on each side.
- **Item:** A supply or terrain card placed on a hex, such as a shield, potion, fence, or bramble. Character cards and Soup of Seeing are not map items.
- **Placement distance:** The minimum number of steps between two hexes through adjacent hexes. A roll of 2–6 allows an item on an empty non-edge hex at exactly that distance from at least one active character; the path does not have to be straight.
- **Committed roll:** Clicking **Roll to place** spends the selected item card and one action. A 1 places the item randomly; a 2–6 requires choosing an eligible hex if one exists. If none exists, or there are no active characters, placement is random on an empty non-edge hex.
- **Hidden item:** An opponent-placed map item. It looks like an empty hex and its placement is omitted from the opponent's battle log. The owner always sees it; a player who discovers a surviving fence by striking it continues to see that fence.
- **Soup of Seeing:** A consumable card used directly on one of your characters that currently has a possible move. It costs a card and an action, not a die roll, and reveals a snapshot of opponent items in that character's possible movement hexes through the end of your turn. A ram's snapshot includes each hex along its possible charge lines. Multiple uses combine.
- **Charge path:** The three consecutive hexes a battering ram strikes in one direction. It enters cleared hexes one at a time and collects their items in order. A surviving obstacle or Confusion stops its travel but not its remaining strikes; a fatal item stops both.
- **Action allowance:** The shared number of actions each player gets per turn, selected from 1–5 in New Game setup and fixed for that match. Playing a card or moving/attacking with a character spends one action. Extra Attack does not change this allowance.
- **Symmetric board:** Alternating rows have one extra hex. The longer rows extend half a hex beyond the shorter rows on both sides, making the outline mirror across its vertical center at every chosen size.
- **Board size:** The row count and shorter-row width chosen in New Game setup. A match keeps those dimensions until a new game starts. The default is five rows of alternating eight and nine hexes.
- **Shorter-row width:** The number of hexes in rows 1, 3, 5, and so on, chosen from 6–12. Rows 2, 4, 6, and so on each contain one additional hex.
- **Character activation:** One move or attack by a character, costing one player action even if the attack fails. Each character gets one normal activation per turn; deployment and receiving Soup of Seeing do not use it. A character may use a stored Extra Attack for one second activation if another player action is available, but never more than twice in one turn.
- **Stored Extra Attack:** A non-stacking bonus held by the character that collected an Extra Attack item until it uses a second activation in a turn. It does not add player actions. A ram can charge twice in one turn before its required rest turn; an unused bonus survives that rest.
- **Encounter cue:** A brief on-board description and visual effect shown when a character claims an item or strikes a fence. Hidden items are named only when encountered. Multiple cues are shown in event order and cleared at turn handoff.
- **Hit cue:** A brief lunge from the attacker, a flash or shake on the defender, and a floating damage number. A shield block instead shows a shield cue. Motion is reduced for players who request reduced motion on their device.
- **Isometric view:** The default fixed perspective, with equal-height raised hexes and upright character icons, labels, and effects. It changes appearance only; movement, attacks, and hidden-item visibility stay the same.
- **Flat view:** The original overhead board, available from the View control beside How to play and New game. Switching views does not restart a match; the choice persists across new games during the current visit.
- **Blacksmith icon (⚒):** Crossed tools identify a Blacksmith on its card and on the board.
- **Battering Ram icon (🪵):** A log identifies the Battering Ram on its card and on the board, distinct from the Blacksmith's tools.
